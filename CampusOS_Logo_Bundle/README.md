# CampusOS Logo Bundle

This bundle was created from the supplied 1024 × 559 PNG. The transparent exports use automatic pale-background removal; inspect edges before large-format printing.

## Included
- `PNG/Transparent`: full horizontal logo and symbol-only mark with transparency.
- `PNG/White`: full logo and mark on a clean white background.
- `WebP`: optimized web exports.
- `SVG`: SVG containers with the supplied raster artwork embedded (not true path-vector artwork). For unlimited-quality scaling, request a professional vector redraw or provide the original AI/EPS/SVG source.
- `Icons`: square app icons, transparent 512px source, and multi-size favicon.
- `Brand_Guide`: quick usage notes.

## Suggested brand colors (visual estimates from the PNG)
- Campus navy: `#0B4F88`
- Campus cyan: `#08C4CC`
- Supporting blue: `#168BD0`
- Supporting slate: `#6D7C88`
- White: `#FFFFFF`

## Usage
- Use transparent PNG/WebP over colored backgrounds.
- Use white-background assets on white/light surfaces.
- Use the symbol-only icon for favicon, app launcher, and compact avatars.
- Keep clear space around the mark and do not stretch the logo.

## Important format note
The SVG files are wrappers containing embedded PNG pixels. They scale as an SVG file but the artwork itself remains raster resolution. They are not editable vector paths.
